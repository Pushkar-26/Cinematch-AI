# 🎬 Cinematch-AI

AI-powered movie recommendation system using NLP and machine learning techniques.

---

## 🌐 Live Demo

[Open Cinematch-AI](https://cinematch-ai-pushkar.streamlit.app/)

---

## 🚀 Features

- Recommend similar movies instantly
- Content-based recommendation system
- Uses movie metadata like genres, cast, and overview
- Clean and interactive interface
- Fast and responsive recommendations

## 📌 How It Works

The system analyzes movie metadata such as genres, cast, keywords, and movie descriptions. Using NLP vectorization techniques and cosine similarity, it recommends movies with similar content and characteristics based on user input.
